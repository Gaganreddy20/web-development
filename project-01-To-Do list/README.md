# TaskFlow — To-Do List App

A simple, responsive To-Do List application that helps students organize daily tasks, track progress, and stay productive.

## Algorithm
1. Start the application.
2. Display the To-Do List interface.
3. Load previously saved tasks from localStorage.
4. Display all saved tasks on the screen.
5. Wait for the user to perform an action.
6. If the user adds a task:
   - Read the task title.
   - Check whether the title is empty.
   - If valid, add the task to the list.
7. If the user edits a task, update its title.
8. If the user deletes a task, remove it from the list.
9. If the user marks a task as completed, update its status.
10. If the user selects a filter, display All, Pending, or Completed tasks accordingly.
11. Save the updated task list to localStorage.
12. Refresh the displayed task list.
13. Repeat steps 5–12 until the user leaves the application.
14. End.

## Features

-  Add new tasks
-  Edit existing tasks
-  Delete tasks
-  Mark tasks as completed
-  Filter tasks by All, Pending, and Completed
-  Save tasks using browser localStorage
-  Responsive design for mobile and desktop
